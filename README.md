# calculadora-nutricional
Una calculadora nutricional lista para ser editada a tu conveniencia

Edita los macros y listo!

Para agregar comidas, asegurate de modificar el javascript para reflejar el nombre de comida de la lista y terminar cada item (menos el ultimo) con un ','.
